# Galeri Foto

## Tentang Project

Galeri Foto adalah website berbagi dan mengelola foto yang memungkinkan pengguna untuk mengunggah, melihat, menyimpan, dan berinteraksi dengan foto.

Website ini dibuat dengan konsep galeri foto digital yang menyediakan berbagai fitur untuk mengelola koleksi foto dan berinteraksi dengan pengguna lain.

## Fitur

- Registrasi dan Login
- Mengelola Profil Pengguna
- Mengunggah Foto
- Mengedit dan Menghapus Foto
- Membuat dan Mengelola Album
- Like Foto
- Komentar Foto
- Menyimpan Foto
- Favorit
- Follow dan Unfollow Pengguna
- Notifikasi Aktivitas
- Pencarian dan Menjelajahi Foto

## Teknologi yang Digunakan

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
